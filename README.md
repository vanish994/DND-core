# DND Core

Núcleo independente do jogo D&D, contendo o Rule Engine e o Orquestrador, sem implementação de Mestre de Jogo (MJ).

Este repositório está sendo montado a partir dos componentes correspondentes de `vanish994/DND-projeto-IA`. A primeira etapa preserva o código dos dois blocos e seus dados necessários; testes e isolamento serão documentados conforme forem verificados.
